Nod v1.0.1 is a maintenance release for the first public release line. It keeps
the v1.0.0 artifact set intact and focuses on notification reliability: APNs
push delivery recovers from Apple's provider-token rate limits, and the macOS
app keeps realtime sync alive while it sits quietly in the menu bar.

## What's Changed

- The APNs relay now caches its provider JWT and refreshes it only inside
  Apple's valid reuse window. This avoids `429 TooManyProviderTokenUpdates`,
  which could stop push delivery to devices with registered APNs tokens.
- The macOS app now holds a ProcessInfo activity assertion for its lifetime so
  App Nap does not throttle the runtime's WebSocket sync while Nod is idle in
  the menu bar. New requests should surface without needing to refocus the app.
- The local compose helper repairs the older macOS APNs bundle id value when
  provisioning relay secrets.
- README screenshots now show the verified macOS, Windows, and terminal clients.

and notarized, Windows remains an unsigned ZIP that should be verified against
`SHA256SUMS`, and server/TUI archives are unsigned portable binaries.
