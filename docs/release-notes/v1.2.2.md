Nod v1.2.2 adds quick answers to the macOS sidebar context menu.

## Changes since v1.2.1

- Right-click an informational request to **Acknowledge**, or an ordinary
  choice card to select a safe answer directly.
- Destructive options, options requiring text, open-only actions and value
  cards are excluded from quick answers. Use the detail view for those cards.
- Menu answers use the existing signed submission and GET-receipt path. The
  original rendered digest, server and request are checked again at click time;
  stale, expired, already-handled and uncertain submissions are guarded against.
- Automatic acknowledgement and normal left-click navigation are preserved.

No server, API, request-digest or decision-signing contract changes. Production
servers do not need redeployment for this client-only feature.
