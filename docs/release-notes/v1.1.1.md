Nod v1.1.1 is an asset-only release: the Nod mascot artwork now ships as the app
icon and menu-bar glyph everywhere Nod runs. Nothing else changes — no
functional, API, server, protocol or signing-byte changes — so v1.1.1 keeps the
v1.1.0 behaviour and install/upgrade path intact.

> Status: **unsigned prep.** The v1.1.1 binaries in this tree are built unsigned
> for validation. No Developer ID signing, notarization or stapling has been run
> yet, and no artifact has been published.

## What's Changed

- The iOS, macOS and desktop (Tauri) apps use the new Nod mascot app icon. All
  AppIcon sizes were regenerated from one white 1024 px master, so the icon
  ladder and the App Store marketing image are pixel-consistent.
- The macOS menu-bar item and the desktop tray item use the mascot line-art
  glyph as a template image, so macOS tints it for light and dark menu bars and
  for the selected state. The desktop tray keeps its 64 px asset and copies of
  the bundled web/README icon were refreshed at their existing pixel sizes.
- Bundled desktop web assets and the README/server icon are the same white
  master, so the in-app enrollment dialog matches the icon on the Dock,
  taskbar and home screen.

## Verification Notes

There are no code, protocol or signing-byte changes to verify: signed decision
bytes, the signing contract, the server API and the on-disk state format are all
identical to v1.1.0. Validation for this release is visual — app icon at every
catalog size and the menu-bar/tray glyph on light and dark menu bars — plus the
usual build and test pass.

Signing expectations follow v1.1.0 once this prep is signed: macOS as a
Developer ID signed, notarized and stapled DMG, Windows as an unsigned ZIP
verified against `SHA256SUMS`, and server/TUI archives as unsigned portable
binaries.
