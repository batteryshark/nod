Nod v1.2.4 shows more rows per page in the admin panel.

## Changes since v1.2.3

- Admin tables (users, devices, channels, tokens, recent requests and push
  deliveries) show 20 rows per page, or 10 on narrow screens, instead of 3 to 5
  depending on window size. Search and Previous/Next paging are unchanged.

No server API, request-digest, decision-signing or client behaviour changes.
